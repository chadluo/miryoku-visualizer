# W3C design system

`styles/core.css`, `styles/advanced.css`, the Noto Sans fonts and `images/quote-bg.png` are copied unmodified from the
[W3C design system](https://design-system.w3.org/) (`/dist/assets/`, version 1.4.3), which is published under the
[W3C Software and Document License](LICENSE.md).

The app uses its `button`, `field`, `field-label` and `note` components. The design system has no dark mode; the page
background and text colours are overridden in `src/styles.css`.
